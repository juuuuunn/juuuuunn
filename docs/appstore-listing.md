## 説明文（4,000字以内）

```
日本語の知恵が詰まった1,117語を収録した、ことわざ・慣用句・四字熟語の学習アプリです。

【特徴】

■ 豊富な収録数
ことわざ・慣用句・四字熟語を合計1,117語収録。意味・読み方・例文をセットで確認できます。

■ 毎日届く「今日のことわざ」
アプリを開くたびに、その日のことわざが大きく表示されます。毎日少しずつ語彙を広げましょう。

■ カテゴリ別に学ぶ
「努力・根気」「知恵・学び」「人間関係」「自然・時間」「行動・判断」「運・運命」「感情・心」の7カテゴリから絞り込んで学習できます。

■ 4択クイズで腕試し
・ことわざを見て意味を答える
・意味を見てことわざを答える
の2形式から選べるクイズ機能付き。カテゴリを絞って集中特訓も可能。正答率をグラフで確認できます。

■ 毎日の通知
1日最大3回、好きな時刻に「今日のことわざ」を通知でお届け。カテゴリを指定して、学びたいジャンルだけを受け取ることもできます。

■ フリガナ対応
すべてのことわざにフリガナ付き。難しい漢字も安心して読めます。

■ 検索・シェア
キーワードやカテゴリで素早く目的のことわざを探せます。気に入ったことわざはそのまま友達にシェアできます。

【こんな方におすすめ】
・日本語の表現力を豊かにしたい方
・受験・資格試験の語彙対策をしたい学生
・日本語を学んでいる外国人の方
・子どもの語彙教育に活用したい親御さん

広告なし・課金なし・完全無料でご利用いただけます。
```

## App Store スクリーンショット撮影ガイド

以下の5画面を順番に撮影してください（6.7インチ iPhone 推奨）。

1. **今日のことわざ**（ホーム画面）
   - 日付・ことわざカード・意味・例文が見えるようにスクロールせず表示

2. **ことわざ一覧**（一覧タブ）
   - カテゴリフィルターと一覧が両方見える状態

3. **ことわざ詳細**
   - ことわざ・フリガナ・意味・例文の全体

4. **クイズ設定画面**
   - 出題形式・カテゴリ・問題数の選択肢が見える状態

5. **クイズ回答画面**（正解フィードバック表示中）
   - 「正解！」バナーと4択の色付きフィードバックが見える状態

6. **クイズ結果画面**（任意）

## プライバシーポリシー URL

GitHub Pages などで `docs/privacy-policy.html` を公開し、そのURLを登録してください。

例： `https://juuuuunn.github.io/juuuuunn/privacy-policy.html`

GitHub Pages 有効化手順：
1. リポジトリの Settings → Pages
2. Source: Deploy from a branch → `main` / `docs` フォルダを選択
3. Save → 数分後に URL が発行される
